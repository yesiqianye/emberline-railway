# 余烬铁路

一款支持电脑和手机浏览器的中文增量游戏。从余烬机务段启程，配置蒸汽列车的车厢，穿过四个区域、十二座车站，沿 588 公里铁路恢复货运。完整旅程约三小时。

[在 GitHub Pages 上游玩](https://yesiqianye.github.io/emberline-railway/)

进度自动保存在当前浏览器中，最多结算八小时离线收益。跨设备或从旧站点迁移时，在设置中导出备份，再到新站点导入。

## 工坊生产

开局的工作台每秒生产 1 个机件，初始库存足够购入第一台车床，将产速提高到每秒 2 个。用机件添置装配台后，车床数量会自行增长。解锁自动产线后，连装配台也会自动生产。每代累计产量达到里程碑会提高各级设备的产速。自动添置的车床和装配台需要工位，购入更多装配台或产线可扩充工位。老存档中超过工位的设备会作为备用，扩建后即可投入生产。

在驾驶台可以把机件装车托运，到站增收运票，从第 2 代工坊开始，还可以在途中花机件快修一次，抵扣发车时全程的 8%。第一站的托运价是 40 机件，到站加收 4 运票。各站报价随路程推进而提高。

工坊换代获得永久蓝图，铁路进度、在途行程、已装车的备件和车库改装都会保留。车库有三种改装可选，每级分别需要 1、2、3 张蓝图。节煤喷嘴每级降低 8% 发车耗煤，快卸货架每级提高 15% 基础运票报酬，检修机臂每级给快修多抵扣全程的 4%。在途列车按发车时的基础运价结算。把蓝图用在改装上，仍可享有按累计蓝图计算的工坊产量、煤钢产量和车速加成。

## 行车与调度

自动添煤默认开启，每 0.65 秒一铲，驾驶台显示的每分钟产量已包含添煤。线路图列出发车物资、到站报酬和每分钟净收益，方便比较直达正线和货运支线。

停靠时可以用运票采购燃煤和钢材，各可采购一批，到站后补货。例如前往曙光总站前，12 张运票可换 9,310 煤，13 张可换 90 钢。运票也可用于承包订单、雇用替班组和优先通行。

沿途信号的补给按当前自动产量计算，单次最多相当于 45 秒。每程最多接两单车上作业，第二单在行程过半后开放。作业报酬在接单时锁定，正确核对货单有额外收益。出现沿途信号或待结算作业时，货运站导航会亮红点。

十二站全部开通后，可以从曙光总站继续派出海湾环运班列。环运正线的基础行程为 6 分钟，同样可以托运备件、途中快修并获得到站报酬。累计蓝图超过 18 张后，每多一张，环运托运一批备件就能再多赚一张运票。运价在装车时锁定。

## 本地运行

在仓库根目录执行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。项目使用原生 HTML、CSS 和 JavaScript 模块，无需安装依赖或构建。
