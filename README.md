# 余烬铁路

一款支持电脑和手机浏览器的中文增量游戏。从余烬机务段启程，配置蒸汽列车的车厢，穿过四个区域、十二座车站，沿 588 公里铁路恢复货运。完整旅程约三小时。

[在 GitHub Pages 上游玩](https://yesiqianye.github.io/emberline-railway/)

进度自动保存在当前浏览器中，最多结算八小时离线收益。跨设备或从旧站点迁移时，在设置中导出备份，再到新站点导入。

## 行车与调度

自动添煤默认开启，每 0.65 秒一铲，驾驶台显示的每分钟产量已包含添煤。线路图列出发车物资、到站报酬和每分钟净收益，方便比较直达正线和货运支线。

沿途可用煤安排车上作业，核对货单可以提高结算报酬。运票可以用于站内采购、承包订单、雇用替班组，或购买本程的优先通行。出现沿途信号或待结算作业时，货运站导航会亮红点。

## 本地运行

在仓库根目录执行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。项目使用原生 HTML、CSS 和 JavaScript 模块，无需安装依赖或构建。
